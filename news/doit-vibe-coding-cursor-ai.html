책 소개

바이브 코딩 시대에는 코드를 잘 짜는 능력보다 AI와 협업하며 아이디어를 실제 결과물로 완성하는 경험이 중요합니다. 많은 사람이 AI로 코드를 생성하는 데는 익숙해졌지만, 실제 서비스를 끝까지 완성하는 데는 어려움을 겪습니다. AI에게 적절한 기능을 요청하고, 생성된 결과를 검토하며, 오류를 수정하고, 배포까지 이어 가는 과정이 생각보다 쉽지 않기 때문입니다.

《Do it! 바이브 코딩 + 커서 AI》는 5가지 실전 프로젝트를 직접 완성하며 아이디어를 실제 서비스로 만드는 전 과정을 경험하도록 기획했습니다. 개발 환경 설정부터 시작해 AI에게 기능을 요청하고, 구현 결과를 테스트하며 오류를 수정한 뒤 배포까지 진행하는 실제 서비스 제작 과정을 단계별로 따라갑니다. 그 결과 AI와 협업하는 방식은 물론, 각 서비스를 구현하는 데 필요한 기술 스택도 자연스럽게 익힐 수 있습니다.

가계부 웹 사이트, 여행 기록 앱, 카카오톡 대화 분석기, 주식 데이터 분석기, 논문 요약 대시보드까지 총 5가지 프로젝트를 완성하며 웹·앱·데이터 분석·AI 자동화 등 다양한 형태의 서비스를 직접 만들어 봅니다. 기능 구현에서 끝나지 않고 수파베이스로 데이터베이스를 연동하고, 지도 API로 외부 데이터를 연결하며, 버셀·스트림릿 커뮤니티 클라우드로 배포까지 진행해 실제 사용할 수 있는 서비스로 완성합니다.

이 책에서 만드는 5가지 실전 프로젝트

  1. 자산 관리 챗봇을 탑재한 가계부 웹 사이트 — Next.js · 수파베이스 · 제미나이 · 버셀 배포
  2. 지도 기반 여행 아카이브 플러터 앱 — 플러터 · 구글 지도 API · 사진 메타데이터
  3. SNS(카카오톡) 대화 패턴 분석 대시보드 — 파이썬 · 스트림릿
  4. 실시간 주식 차트 분석 서비스 — yfinance · 캔들스틱/이동평균선 차트
  5. 최신 논문 AI 요약 서비스 — 크롤링(뷰티풀숩) · 제미나이 요약 · 대시보드

출판사 서평

바이브 코딩, 개발이 처음이어도 시작할 수 있나요?

‘코딩을 몰라도 AI가 다 만들어 준다’는 이야기는 많이 들었지만, 막상 시작하려면 무엇부터 해야 할지 막막한 경우가 많습니다. 이 책은 개발 환경 설정부터 커서 AI로 기능을 구현하고, 테스트와 오류 수정, 배포까지 실제 프로젝트를 진행하는 과정을 차근차근 안내합니다. AI에게 코드를 맡기기만 하는 것이 아니라 결과를 확인하고 수정하며 원하는 방향으로 발전시키는, AI와 협업하는 개발 방식을 자연스럽게 익힐 수 있습니다.

커서 AI만으로도 서비스를 제대로 만들 수 있나요?

중요한 것은 AI가 작성한 코드를 그대로 쓰는 것이 아니라, 결과를 확인하고 수정하며 하나의 서비스를 완성하는 과정입니다. 이 책에서는 웹·앱·데이터 분석·AI 자동화까지 서로 다른 5가지 프로젝트를 직접 만들며 다양한 개발 분야를 경험합니다.

다른 책과 어떤 점이 다른가요?

커서 AI의 기능·사용법 소개에 그치지 않고, Next.js·플러터·파이썬·수파베이스·스트림릿 등 다양한 기술 스택을 특정 언어나 프레임워크에 국한하지 않고 폭넓게 경험합니다. 완성한 프로젝트는 버셀과 스트림릿 커뮤니티 클라우드로 직접 배포해 실제 사용할 수 있는 서비스로 만듭니다. 〈알아 두면 좋아요〉로 핵심 개념을, 〈한 걸음 더!〉로 프로젝트 확장 아이디어를 제공해 자신만의 서비스로 응용할 수 있습니다.

  • AI와 함께 포트폴리오 프로젝트를 완성하고 싶은 대학생과 취업 준비생
  • MVP를 빠르게 만들어 검증하고 싶은 예비 또는 1인 창업가

저자 소개 — 허주희

시스템공학과 컴퓨터공학을 전공하며 AI와 소프트웨어 개발을 연구했다. 대학 재학 중 생성형 AI 서비스를 직접 개발하고, 바이브 코딩으로 아이디어를 실제 서비스로 구현했다. 커서를 활용해 AI 만화 생성 서비스를 개발했으며, 5,000명 이상의 수강생과 3억 회 이상의 콘텐츠 조회수, 200건 이상의 광고·비즈니스 계약, 6억 원 이상의 누적 매출을 달성했다. 청년창업사관학교 선정과 프라이머(Primer)의 투자를 유치하며 생성형 AI 서비스의 개발부터 사업화까지 전 과정을 경험했다. 현재 AI 크리에이터 IP 인큐베이터 ‘만화제면소’를 창업해 생성형 AI 기반 콘텐츠 제작과 크리에이터 성장을 지원하고 있다.

자주 묻는 질문 (FAQ)

Q. 《Do it! 바이브 코딩 + 커서 AI》는 어떤 책인가요?

커서(Cursor) AI를 활용해 5가지 실전 프로젝트를 직접 완성하며 바이브 코딩으로 아이디어를 실제 서비스로 만드는 과정을 배우는 실전 입문서입니다. 허주희가 썼고 이지스퍼블리싱에서 2026년 8월 20일 출간했으며, 336쪽 28,000원입니다.

Q. 바이브 코딩(Vibe Coding)이란 무엇인가요?

바이브 코딩은 코드를 직접 한 줄씩 작성하기보다 AI에게 원하는 기능을 설명해 코드를 생성하고, 그 결과를 확인·수정하며 서비스를 완성하는 개발 방식입니다. 코드를 많이 아는 것보다 무엇을 만들지, 어떻게 구현하고 연결할지를 이해하는 능력이 중요합니다.

Q. 이 책에서는 어떤 프로젝트를 만드나요?

가계부 웹 사이트(자산 관리 챗봇 탑재), 지도 기반 여행 아카이브 플러터 앱, 카카오톡 대화 패턴 분석 대시보드, 실시간 주식 차트 분석 서비스, 최신 논문 AI 요약 서비스 등 5가지 실전 프로젝트를 완성합니다.

Q. 개발이 처음이어도 따라 할 수 있나요?

네. 커서 가입·설치 등 개발 환경 설정부터 시작해 AI에게 기능을 요청하고, 결과를 테스트하고 오류를 수정한 뒤 배포까지 단계별로 안내하므로 개발이 처음인 사람도 따라 할 수 있습니다.

Q. 어떤 기술 스택을 배우나요?

Next.js, 플러터(Flutter), 파이썬, 수파베이스(Supabase), 스트림릿(Streamlit) 등 다양한 기술 스택을 다루며, 버셀(Vercel)과 스트림릿 커뮤니티 클라우드로 실제 배포까지 진행합니다. 특정 언어나 프레임워크에 국한하지 않고 AI와 협업하는 방식을 폭넓게 경험합니다.

Q. 커서(Cursor) AI란 무엇인가요?

커서는 AI가 내장된 코드 에디터로, 자연어로 기능을 요청하면 코드를 생성·수정해 주는 바이브 코딩의 핵심 도구입니다. 이 책은 커서를 활용해 실제 서비스를 처음부터 끝까지 만드는 과정을 다룹니다.

Q. 누구에게 추천하는 책인가요?

아이디어를 실제 서비스로 만들고 싶은 기획자·마케터, 직접 프로토타입을 만들고 싶은 PM, AI로 포트폴리오 프로젝트를 완성하려는 대학생·취업 준비생, MVP를 빠르게 검증하려는 예비 또는 1인 창업가에게 적합합니다.

이지스퍼블리싱 홈페이지(www.easyspub.co.kr)의 자료실에서 도서명으로 검색하거나, 저자 깃허브(github.com/diatomicC/doit_vibe_coding_lab)에서 프롬프트 파일과 결과 코드를 내려받을 수 있습니다.
